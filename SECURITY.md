# Security

If you find a security problem in MythosMaphack, please **do not open a public issue**.

Report it privately: join the [D2R Mythos Discord](https://discord.com/invite/d2rmythos) and send a
direct message to a staff member, saying it is a security report. We will reply there.

Never send anyone your Battle.net password or login details. Nobody from D2R Mythos will ask for them.
